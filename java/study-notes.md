# Java Beginner (1)・(2) 復習ノート

授業の進度に合わせて、基本型と制御構文から配列までを小さく整理しました。コードを読むときは、変数の値とループ条件を一つずつ追うと流れをつかみやすくなります。

## Beginner (1)

### Primitive Type

Javaの基本データ型には、整数の`int`、小数の`double`、1文字の`char`、真偽値の`boolean`などがあります。`String`は便利ですが基本型ではなく、文字列を表すクラスです。変数を宣言するときは、入れる値に合う型を選びます。

### if

`if`は条件が`true`かどうかで処理を分けます。複数の条件を並べるときは、上から順番に確認されるので、先に細かい条件を書くかどうかも大切です。`&&`は「かつ」、`||`は「または」です。

### for と while

回数や範囲が決まっている処理は`for`、条件が続く間くり返す処理は`while`で書けます。`while`では、条件に使う値を更新し忘れると終わらないことがあります。

### break と continue

`break`は現在のループを終了します。`continue`はその回の残りを飛ばし、次のくり返しへ進みます。`LoopsAndControlFlow.java`では、休みの日を`continue`で飛ばし、合計時間が目標に達したら`break`しています。

## Beginner (2)

### 二重ループ

ループの中にもう一つのループを書くと、表の行と列のような組み合わせを順番に処理できます。内側のループは、外側の1回ごとに最初から最後まで実行されます。3行×4列なら、内側の処理は合計12回です。

### 配列

同じ型の値を複数まとめるときは配列を使います。要素番号（添字）は`0`から始まり、要素数は`length`で確認できます。最後の要素の添字は`length - 1`です。

`ArrayBasics.java`では、添字で値を更新し、`for`で全要素を取り出しています。合計を`int`で計算したあと平均を求めるため、割り算の前に`double`へ変換しています。変換しない整数同士の割り算では小数部分が切り捨てられます。

## 自分で値を変えて確認する

- `PrimitiveTypesAndIf.java`の勉強時間とレベルを変え、どの条件に入るか予想します。
- `LoopsAndControlFlow.java`の休みの日や目標時間を変え、`continue`と`break`の位置を見ます。
- `NestedLoop.java`の行数と列数を変え、表示件数を数えます。
- `ArrayBasics.java`の点数を追加・変更し、合計と平均を確かめます。
